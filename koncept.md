# Koncept Flashtrans
1. Tři nápady: (a) nákladní list – web jako přepravní doklad s razítky a řádky, (b) trasa – linka Košice → Trenčín/Bratislava s pobočkami jako zastávkami, (c) ložná plocha – rozměry vozů jako výkres.
2. Výběr: (b)+(c) lehce. Firma má pobočky (Bratislava, Nitra, Trenčín, Poprad, Košice) a pravidelné linky; vozový park má reálné rozměry. Stock fotky klienta jen ve hero a obalech.
3. Sekce: hero (fotka vozů, zelená) → pás výhod → trasa s pobočkami (signature) → sťahovanie → doprava → vozový park (výkresové kartičky) → cenník → ostatné služby → referencie → kontakt. 
4. Písma: Barlow Condensed 600 (nápisy na dodávkách) + Barlow. Paleta: zelená #01753a z loga, žlutá #f2b705 (z jejich banneru s obaly), krémová.
5. Zakázané vzory: žádné.
6. Odlišné od posledních webů (jiný font než Schibsted Grotesk).
